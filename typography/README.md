# 🎨 Sistema de Tipografía y Fuentes — MYNEXT

Esta carpeta contiene la guía oficial de tipografía, jerarquía visual y pares de fuentes para todos los proyectos de desarrollo en **MYNEXT**.

---

## 🔤 Emparejamientos de Fuentes Recomendados

1. **MUSERO x ERTINAS**: Editorial moderno, elegante y limpio.
2. **ELEGIST x MARLINO**: Estilo de lujo, minimalismo sofisticado.
3. **RIVAGE x ERTINAS**: Diseño vanguardista con trazos expresivos.
4. **CLEAN FRAGILE x MIRAVA**: Alta precisión, tecnológico y refinado.
5. **GRANITY x INTER**: UI contemporánea, máxima legibilidad técnica.

---

## 📐 Jerarquía Tipográfica Estricta

- **H1 (Título Principal)**: Gigante, Bold/Black, `tracking-tighter` (-0.04em).
- **H2 (Subtítulo de Sección)**: Grande, SemiBold/Regular.
- **H3 (Eyebrow / Etiqueta)**: Texto superíndice pequeño, sobre el H1.
- **H4 (Cuerpo de Texto)**: Lectura cómoda, ancho máximo recomendado de 65 caracteres (`max-w-prose`).
- **CTA (Botones y Acciones)**: Texto pequeño, MAYÚSCULAS, espaciado de letras amplio (`tracking-widest`).

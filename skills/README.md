# 🎯 Skills de Desarrollo — MYNEXT

En esta carpeta se encuentran las **skills** personalizadas registradas para Antigravity IDE y entornos de desarrollo web de MYNEXT.

---

## 📚 Índice de Skills

### 1. `gpt-taste/`
- **Descripción**: Reglas y patrones de diseño vanguardistas para evitar estéticas genéricas y aplicar acabados ultra premium.

### 2. `i18nstack/`
- **Descripción**: Buenas prácticas y patrones para internacionalización (i18n) sin romper contenedores o layouts.

### 3. `motion-design/`
- **Descripción**: Definición de curvas `cubic-bezier`, animaciones escalonadas (*stagger*), microinteracciones y efectos de movimiento avanzados con GSAP/CSS.

### 4. `skill-tailwind/`
- **Descripción**: Guía y directivas centralizadas para Tailwind CSS v4 con variables de tema `@theme`.

### 5. `uipro-max/`
- **Descripción**: Estructuras avanzadas de componentes, Bento Grids y sistemas de diseño para experiencia de usuario (UX/UI) de nivel profesional.

### 6. `setup-mynext/`
- **Descripción**: Inicializa y levanta el entorno de desarrollo local (setup.sh, rama dev, docs) al iniciar un nuevo proyecto o sesión.

# 🌍 Skill de Localización: i18nstack

Evita traducciones literales genéricas de IA y protege la estructura del layout frente a la expansión de caracteres del español u otros idiomas.

## Directrices
1. **No rompas el diseño**: Cuando traduzcas, asegúrate de que la longitud de las palabras encaja en los contenedores existentes (botones, tarjetas).
2. **Pseudo-traducción**: Si estás diseñando un componente nuevo, usa textos ligeramente más largos para asegurarte de que soporta idiomas expansivos como el español o el alemán.
3. **Calidad sobre literalidad**: Adapta el tono de voz para que suene natural, no traduzcas "palabra por palabra".
4. **Validación de variables**: Asegúrate de que las variables (ej. `{userName}`) no se rompan ni cambien de formato durante la traducción.

# 🎨 Playbook de Diseño Dinámico: gpt-taste

Esta *skill* asegura que las interfaces web rompan la estética estandarizada de IA. 

## 1. Jerarquía Tipográfica Estricta
SIEMPRE estructura la tipografía usando la siguiente jerarquía visual:
- **H1 (TÍTULOS)**: Tamaño gigante, peso bold/black, tracking ajustado.
- **H2 (SUBTÍTULOS)**: Tamaño grande, peso semibold o regular con buen contraste.
- **H3 (Eyebrow)**: Tamaño medio-pequeño, a menudo usado encima del H1 como introducción.
- **H4 (Bloque de texto)**: Cuerpo del texto, legible, ancho máximo de 65 caracteres para no cansar la vista.
- **CALL TO ACTION (CTA)**: Letra extra pequeña, todo en MAYÚSCULAS (uppercase), con tracking/letter-spacing muy amplio.

## 2. Emparejamiento de Fuentes Premium (Modern Font Pairings)
Cuando generes o sugieras diseños, prioriza SIEMPRE estas combinaciones tipográficas comprobadas por MYNEXT (busca alternativas de Google Fonts solo si estas no están disponibles, pero usa este estilo visual):
- *Designed with Purpose*: **MUSERO x ERTINAS**
- *Form Meets Function*: **MAGEITAN x MENIRVA**
- *Simple Pleasure*: **MONTELISA x MAGI SANS**
- *Clean Lines Clear Vision*: **SAMTHON x NUVICA**
- *Built for the Future*: **MILKYRAIN x OPEN SANS**
- *Modern by Nature*: **ELEGIST x MARLINO**
- *Simple Forms, Strong Ideas*: **RIVAGE x ERTINAS**
- *Minimal But Meaningful*: **GRANITY x INTER**
- *Crafted with Precision*: **CLEAN FRAGILE x MIRAVA**
- *Clarity Over Complexity*: **MORELY x KANETIN**

## 3. Composición Avanzada
- Ajusta automáticamente *trackings* negativos en encabezados masivos.
- Aplica balanceo de líneas (`text-wrap: balance`) para evitar palabras huérfanas.
- Limita el ancho de los párrafos a 65 caracteres (`max-w-prose` o `max-w-2xl`).
